# CoDef JISA reproducibility artifact

This public repository contains the anonymized source code, experiment protocols, input data, graph-level outputs, and analysis scripts associated with the CoDef JISA manuscript. It is based on the integrity-checked review artifact and excludes author-identifying title-page and submission files.

Start with [`ARTIFACT_README.md`](ARTIFACT_README.md) for the experiment inventory, environments, and reproduction steps. `ARTIFACT_SHA256.json` records hashes for the archived payload files. The archive and repository represent the paper-branch experiments; older competition-branch results are not part of the reported claims.
